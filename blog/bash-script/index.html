BASH SCRIPT

THE DEFINITIVE GUIDE TO MODERN BASH SCRIPTING

Bash (Bourne Again Shell) is the universal command language of Unix-like systems. From rapid task automation, hardware security research, and CTF exploit tooling to robust DevOps deployment pipelines, mastering Bash empowers you to manipulate processes, files, and streams with unmatched speed and control.


SETTING UP & THE SHEBANG LINE

A Bash script is simply an executable plain text file containing a sequence of commands. Always ensure your script begins with a shebang (#!), which tells the OS loader which interpreter binary to invoke.

bash 
#!/usr/bin/env bash
# Best practice: '/usr/bin/env bash' locates the bash binary in the user's $PATH 
# rather than hardcoding /bin/bash (essential for macOS / BSD portability)

Make your script executable using chmod and execute it directly:

bash 
chmod +x myscript.sh
./myscript.sh

VARIABLES & SPECIAL PARAMETERS

In Bash, variable assignment must have NO spaces around the = sign. Prefix the variable name with $ (or ${VAR}) to reference its contents.

bash 
# Assignment (NO spaces around =)
NAME="Narikodan"
AGE=23
READONLY_VAR="Immutable value"
readonly READONLY_VAR

# Referencing variables
echo "Welcome, ${NAME}! You are ${AGE} years old."

Special Built-in Variables Table

VariableMeaning / Description
$0Name of the running script.
$1, $2, ... $9, ${10}Positional command-line arguments passed to the script.
$#Total number of positional arguments passed.
$@All positional arguments as individual quoted words (e.g. "$1" "$2" ...). Always prefer this!
$*All positional arguments joined into a single string separated by the first char of $IFS (usually space).
$?Exit status of the most recently executed command (0 = success, non-zero = error).
$$Process ID (PID) of the current running shell/script.
$!Process ID (PID) of the most recently spawned background job.

CLI ARGUMENTS & FLAG PARSING WITH getopts

Hardcoding values makes scripts brittle. You can pass arguments on invocation or parse standard Unix flags (e.g., ./tool.sh -u admin -p 8080 -v) using the built-in getopts utility:

bash 
#!/usr/bin/env bash

# Default values
PORT=8080
VERBOSE=false

usage() {
    echo "Usage: $0 [-u user] [-p port] [-v] [-h]"
    exit 1
}

# The leading ':' silences default error messages; letters followed by ':' require an argument
while getopts ":u:p:vh" opt; do
    case "$opt" in
        u) USERNAME="$OPTARG" ;;
        p) PORT="$OPTARG" ;;
        v) VERBOSE=true ;;
        h) usage ;;
        :) echo "Error: Option -$OPTARG requires an argument." >&2; exit 1 ;;
        \?) echo "Error: Invalid option -$OPTARG." >&2; usage ;;
    esac
done
shift $((OPTIND - 1)) # Discard parsed options, remaining are positional arguments

echo "Deploying for User: ${USERNAME:-'Guest'} on Port: ${PORT}"
$VERBOSE && echo "[INFO] Verbose mode enabled."

PARAMETER EXPANSION & STRING HACKS (PURE BASH)

Avoid spawning external subshells like sed, awk, or cut for simple string parsing. Bash's native parameter expansion runs orders of magnitude faster in memory:

bash 
FILE_PATH="/var/log/nginx/access.log.tar.gz"

# 1. Default value fallback (If unset, use default)
PORT="${CONFIG_PORT:-8080}"

# 2. String length
echo "Length of FILE_PATH: ${#FILE_PATH}"

# 3. Substring extraction: ${VAR:offset:length}
STR="HardwareSecurity"
echo "${STR:0:8}"  # Outputs: Hardware
echo "${STR:8}"    # Outputs: Security

# 4. Strip prefix: ${VAR#pattern} (shortest) | ${VAR##pattern} (longest)
echo "${FILE_PATH##*/}" # Strips everything up to last slash -> "access.log.tar.gz" (Pure basename!)

# 5. Strip suffix: ${VAR%pattern} (shortest) | ${VAR%%pattern} (longest)
FILENAME="backup_2026.tar.gz"
echo "${FILENAME%.*}"   # Strips last extension -> "backup_2026.tar"
echo "${FILENAME%%.*}"  # Strips all extensions -> "backup_2026"

# 6. Search and Replace: ${VAR/pattern/replacement}
GREETING="Hello World World"
echo "${GREETING/World/Bash}"   # Replaces first match -> "Hello Bash World"
echo "${GREETING//World/Bash}"  # Replaces all matches -> "Hello Bash Bash"

I/O REDIRECTIONS, PIPELINES & HEREDOCS

In Unix, everything is a stream. Programs read from standard input (File Descriptor 0 / stdin), write to standard output (FD 1 / stdout), and send diagnostics to standard error (FD 2 / stderr).

SyntaxOperatorFunction
cmd > fileRedirect StdoutOverwrites file with output from cmd.
cmd >> fileAppend StdoutAppends output of cmd to the end of file.
cmd 2> fileRedirect StderrRedirects errors only into file.
cmd > file 2>&1 or cmd &> fileRedirect BothMerges stdout and stderr into file.
cmd &> /dev/nullSilent / DiscardThrows away all standard and error output completely.
cmd1 | cmd2PipeConnects stdout of cmd1 to stdin of cmd2.

Heredocs & Herestrings

Heredocs let you stream multi-line configuration blocks or templates directly into files or commands without messy multi-line echo statements:

bash 
# Generate a multi-line configuration file with variable interpolation
TARGET_IP="192.168.1.50"
cat <<EOF > /tmp/target.conf
# Auto-generated configuration
Host: target-node
IP: ${TARGET_IP}
Timestamp: $(date '+%Y-%m-%d %H:%M:%S')
EOF

# Quoting 'EOF' prevents variable expansion (ideal for code generators):
cat <<'EOF' > /tmp/script_template.sh
#!/usr/bin/env bash
echo "This $VARIABLE will NOT be evaluated right now."
EOF

# Herestring: Feed a variable directly into stdin of a command
MESSAGE="CRITICAL: Memory threshold exceeded"
grep "CRITICAL" <<< "$MESSAGE"

ARITHMETIC & NUMERIC OPERATIONS

Bash natively performs integer arithmetic using $(( ... )) or the evaluation statement (( ... )). Floating-point operations require bc or awk.

bash 
A=15
B=4

# Basic integer arithmetic
SUM=$(( A + B ))       # 19
DIFF=$(( A - B ))      # 11
PROD=$(( A * B ))      # 60
DIV=$(( A / B ))       # 3 (integer division truncates)
MOD=$(( A % B ))       # 3
POW=$(( 2 ** 8 ))      # 256

# Increment / Decrement
(( A++ ))              # A becomes 16
(( B += 10 ))          # B becomes 14

# Floating point calculation via 'bc'
FLOAT_RES=$(echo "scale=3; 15 / 4" | bc)
echo "Float result: $FLOAT_RES"  # Outputs: 3.750

TEST OPERATORS & CONDITIONALS ([[ ... ]])

Always prefer the modern double bracket test [[ ... ]] over the obsolete POSIX single bracket [ ... ]. Double brackets prevent word splitting, allow boolean operators (&&, ||), and enable powerful regex matching with =~.

bash 
FILE="/etc/hosts"
USER_INPUT="192.168.1.100"

# File test operators
if [[ -f "$FILE" && -r "$FILE" ]]; then
    echo "$FILE exists and is a readable regular file."
fi

# String & Regex matching (=~)
if [[ -z "$EMPTY_VAR" ]]; then
    echo "Variable is empty or unset."
fi

if [[ "$USER_INPUT" =~ ^[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}\.[0-9]{1,3}$ ]]; then
    echo "Valid IPv4 address syntax confirmed."
else
    echo "Invalid IP format." >&2
fi

Essential Test Flags Cheatsheet

FlagCategoryCondition Evaluated to True
-e fileFilePath exists (file, directory, socket, device).
-f fileFilePath exists and is a regular file.
-d pathFilePath exists and is a directory.
-s fileFileFile exists and has a size greater than zero.
-x fileFileFile exists and has execute permission.
-z strStringString length is zero (empty).
-n strStringString length is non-zero.

LOOPS: FOR, WHILE & UNTIL

bash 
# 1. C-style for loop
for ((i = 1; i <= 5; i++)); do
    echo "Step: $i"
done

# 2. Iterating through files matching a pattern safely (handles spaces!)
for conf in /etc/*.conf; do
    [[ -e "$conf" ]] || continue # Guard against empty matches
    echo "Auditing config: $conf"
done

# 3. Reading a file line by line safely (preserving whitespace and tabs)
while IFS= read -r line || [[ -n "$line" ]]; do
    echo "Processing line: $line"
done < "targets.txt"

# 4. Until loop (runs until condition turns true)
RETRY=0
until ping -c 1 -W 1 google.com &>/dev/null; do
    echo "Waiting for internet connection..."
    sleep 2
    (( RETRY++ ))
    [[ $RETRY -ge 5 ]] && { echo "Connection timeout"; break; }
done

ARRAYS & ASSOCIATIVE MAPS (HASHMAPS)

Bash supports both zero-indexed linear arrays and associative key-value dictionaries (hashmaps in Bash 4+):

bash 
# --- Indexed Arrays ---
SERVERS=("gateway-01" "db-primary" "cache-node")

# Append element
SERVERS+=("worker-node")

# Array size
echo "Total servers: ${#SERVERS[@]}"

# Iterate over elements
for server in "${SERVERS[@]}"; do
    echo "Connecting to: $server"
done

# --- Associative Arrays (Hashmaps, requires Bash 4+) ---
declare -A PORT_MAP=(
    ["http"]=80
    ["https"]=443
    ["ssh"]=22
    ["mysql"]=3306
)

PORT_MAP["redis"]=6379

# Accessing keys and values
echo "SSH Port is: ${PORT_MAP["ssh"]}"

# Iterate over all keys
for service in "${!PORT_MAP[@]}"; do
    echo "Service: $service -> Port: ${PORT_MAP[$service]}"
done

FUNCTIONS & LOCAL VARIABLE SCOPE

By default, all variables in Bash are global, even when declared inside functions! This is a massive source of bugs. Always declare internal function variables with local.

bash 
# Function definition
calculate_sha256() {
    local target_file="$1" # Scoped locally to this function only
    
    if [[ ! -f "$target_file" ]]; then
        echo "Error: File '$target_file' not found." >&2
        return 1 # Non-zero return signals failure
    fi
    
    local hash
    hash=$(sha256sum "$target_file" | awk '{print $1}')
    echo "$hash" # Functions return data to caller via stdout
    return 0     # Exit code 0 denotes success
}

# Invoking function with command substitution
MY_HASH=$(calculate_sha256 "/bin/ls")
if [[ $? -eq 0 ]]; then
    echo "SHA256 Hash: $MY_HASH"
fi

DEFENSIVE BASH: STRICT MODE & SIGNAL TRAPS

Production Bash scripts should never fail silently. Adopting Unofficial Bash Strict Mode (set -euo pipefail) ensures immediate execution termination when an error occurs, uninitialized variables are accessed, or pipeline steps fail.

bash 
#!/usr/bin/env bash
set -e          # Exit immediately if any command returns a non-zero status
set -u          # Treat unset variables as an error and exit immediately
set -o pipefail # Pipeline status is the code of the LAST failed command (not the last command)

# Safe temporary directory creation with guaranteed cleanup
TMP_DIR=$(mktemp -d)

# Signal Trapping: Runs cleanup function automatically on EXIT, Ctrl+C (INT), or TERM
cleanup() {
    local exit_code=$?
    echo "[INFO] Cleaning up temporary directory $TMP_DIR..."
    rm -rf "$TMP_DIR"
    exit "$exit_code"
}
trap cleanup EXIT INT TERM

# Now your script can safely do work:
echo "Doing work inside $TMP_DIR..."

FILE & DIRECTORY OPERATIONS

Real-world file manipulation patterns:

bash 
LOG_DIR="/var/log/myapp"

# Create directories recursively only if they don't exist
mkdir -p "$LOG_DIR"

# Atomically copy files with preserved timestamps
cp -p "$FILE" "$LOG_DIR/"

# Finding and deleting files older than 14 days
find "$LOG_DIR" -name "*.log" -type f -mtime +14 -exec rm -f {} +

# Reading space-delimited or CSV data cleanly
while IFS=',' read -r col1 col2 col3; do
    echo "Column 1: $col1 | Column 2: $col2"
done < "data.csv"

REAL-WORLD PRODUCTION SCRIPT: SYSTEM BACKUP & HEALTH MONITOR

Here is an end-to-end, production-grade automation script incorporating command-line flags, strict mode, colored status reporting, temporary storage, and signal trapping:

bash 
#!/usr/bin/env bash
set -euo pipefail

# ANSI color codes for terminal logging
RED='\033[0;31m'
GREEN='\033[0;32m'
YELLOW='\033[1;33m'
NC='\033[0m' # No Color

log_info()  { echo -e "${GREEN}[INFO]${NC}  $*"; }
log_warn()  { echo -e "${YELLOW}[WARN]${NC}  $*"; }
log_error() { echo -e "${RED}[ERROR]${NC} $*" >&2; }

# Default parameters
BACKUP_DIR="/tmp/backups"
SOURCE_DIR=""
RETENTION_DAYS=7

usage() {
    cat <<EOF
Usage: $0 -s <source_directory> [-d <backup_destination>] [-r <retention_days>]
Options:
  -s  Source directory to back up (Mandatory)
  -d  Destination backup directory (Default: /tmp/backups)
  -r  Retention in days (Default: 7)
  -h  Show this help message
EOF
    exit 1
}

while getopts ":s:d:r:h" opt; do
    case "$opt" in
        s) SOURCE_DIR="$OPTARG" ;;
        d) BACKUP_DIR="$OPTARG" ;;
        r) RETENTION_DAYS="$OPTARG" ;;
        h) usage ;;
        :) log_error "Option -$OPTARG requires an argument."; exit 1 ;;
        \?) log_error "Unknown option -$OPTARG."; usage ;;
    esac
done

[[ -z "$SOURCE_DIR" ]] && { log_error "Source directory (-s) is mandatory."; usage; }
[[ ! -d "$SOURCE_DIR" ]] && { log_error "Source directory '$SOURCE_DIR' does not exist."; exit 1; }

# Safe temp workspace
WORK_DIR=$(mktemp -d)
cleanup() {
    rm -rf "$WORK_DIR"
    log_info "Workspace clean. Execution terminated."
}
trap cleanup EXIT INT TERM

log_info "Initiating backup for: $SOURCE_DIR"
mkdir -p "$BACKUP_DIR"

TIMESTAMP=$(date '+%Y%m%d_%H%M%S')
ARCHIVE_NAME="backup_$(basename "$SOURCE_DIR")_${TIMESTAMP}.tar.gz"
TARGET_PATH="${BACKUP_DIR}/${ARCHIVE_NAME}"

# Create compressed archive
tar -czf "$TARGET_PATH" -C "$(dirname "$SOURCE_DIR")" "$(basename "$SOURCE_DIR")"
log_info "Archive generated: $TARGET_PATH ($(du -h "$TARGET_PATH" | cut -f1))"

# Check disk space percentage
DISK_USAGE=$(df -h "$BACKUP_DIR" | awk 'NR==2 {print $5}' | tr -d '%')
if [[ "$DISK_USAGE" -gt 85 ]]; then
    log_warn "Backup volume is at ${DISK_USAGE}% capacity!"
fi

# Prune older archives
log_info "Purging archives older than ${RETENTION_DAYS} days..."
find "$BACKUP_DIR" -name "backup_*.tar.gz" -type f -mtime +"$RETENTION_DAYS" -exec rm -v {} +

log_info "Backup routine completed successfully."
exit 0
