SHELL PROMPT

SHELL PROMPT CUSTOMISATION USING PS1

In Bash, your command line prompt is controlled by special shell environment variables: PS1, PS2, PS3, and PS4. The PS1 (Prompt String 1) variable defines the primary interactive prompt you see every time you type a command. Customizing PS1 turns an uninspiring terminal into an informative, aesthetically pleasing dashboard.


Open your terminal and test it out right now:
bash 
PS1="hello >> "

To persist your custom prompt permanently across terminal sessions, place the export PS1="..." definition in your ~/.bashrc (or ~/.zshrc).


Key Points

  • Non-Printing Characters: Always wrap ANSI color escape sequences in \[ ... \]. This informs Bash that those characters occupy zero display width on the screen, preventing broken line-wrapping and history scrolling bugs.
  • Resetting Colors: Always conclude your prompt with \[\e[0m\] to ensure that commands typed by the user stay in the default terminal font color.
  • Portability: Standard ANSI 8-color and 16-color codes work everywhere. 24-bit TrueColor (RGB) gives beautiful pastel tones on modern terminal emulators (Kitty, Alacritty, iTerm2, Windows Terminal).

24-Bit TrueColor (RGB) Format

  • \[\e[38;2;⟨R⟩;⟨G⟩;⟨B⟩m\] — Sets precise 24-bit RGB Foreground color.
  • \[\e[48;2;⟨R⟩;⟨G⟩;⟨B⟩m\] — Sets precise 24-bit RGB Background color.
bash 
# Custom emerald green text on dark slate background:
PS1="\[\e[38;2;166;223;144;48;2;20;25;20m\] \u@\h \[\e[0m\] \w >> "

PRO TIP: DYNAMIC GIT BRANCH & EXIT STATUS IN PS1 (PURE BASH)

You don't need heavyweight plugins like Oh-My-Zsh or Starship to see your Git status and previous command success. You can write a lightweight pure Bash prompt in your ~/.bashrc that loads instantly:

~/.bashrc 
# Function: Returns current git branch with clean/dirty indicators
parse_git_branch() {
    local branch
    branch=$(git rev-parse --abbrev-ref HEAD 2>/dev/null) || return
    local status=""
    # Check if working tree has unstaged or staged changes
    [[ -n $(git status --porcelain 2>/dev/null) ]] && status="*"
    echo " (git:${branch}${status})"
}

# Function: Shows green checkmark if last command succeeded, or red cross + exit code
format_exit_status() {
    local exit_code=$1
    if [[ $exit_code -eq 0 ]]; then
        echo "\[\e[32m\]✔\[\e[0m\]"
    else
        echo "\[\e[31m\]✘ [${exit_code}]\[\e[0m\]"
    fi
}

# PROMPT_COMMAND runs right before PS1 is displayed
set_prompt() {
    local LAST_STATUS=$?
    local STATUS_STR
    STATUS_STR=$(format_exit_status "$LAST_STATUS")
    
    PS1="${STATUS_STR} \[\e[38;2;166;223;144;1m\]\u@\h\[\e[0m\]:\[\e[38;2;100;180;255m\]\w\[\e[38;2;255;180;80m\]\$(parse_git_branch)\[\e[0m\]\n\$ "
}

PROMPT_COMMAND=set_prompt
