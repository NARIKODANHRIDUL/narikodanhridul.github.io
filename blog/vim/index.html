VIM EDITOR

MASTERING VIM: THE DEFINITIVE GUIDE

Vim ("Vi IMproved") is a modal, keystroke-driven text editor built for high-velocity software engineering and system administration. Unlike typical graphical editors, Vim treats editing as a language composed of verbs (operators), counts, and nouns (motions/objects). Once internalized into muscle memory, your hands never leave the home row.


Basic Navigation

Moving the Cursor (Home Row):

KeyMovement Purpose
h, j, k, lLeft, Down, Up, and Right respectively.
wMove forward to the beginning of the next word.
WMove forward to next word (separated only by whitespace).
bMove backward to the beginning of the previous word.
BMove backward to previous word (separated only by whitespace).
eMove to the end of the current or next word.
geMove backward to the end of the previous word.

Jumping between Lines & Files:

KeyJump Action
0Jump to the absolute beginning of the line (column 0).
^Jump to the first non-blank character of the line.
$Jump to the end of the current line.
ggJump to the very first line of the file.
GJump to the last line of the file.
[n]G or :[n]Jump directly to line number [n] (e.g. 42G jumps to line 42).
%Jump to matching bracket: (), {}, or [].
H, M, LJump to High (top), Middle, and Low (bottom) of screen viewport.

Scrolling Viewports:

KeyScrolling Action
Ctrl + uScroll viewport UP half a screen.
Ctrl + dScroll viewport DOWN half a screen.
Ctrl + bScroll viewport UP one full page.
Ctrl + fScroll viewport DOWN one full page.
zzCenter screen viewport around current cursor line.
ztScroll line to the Top of the viewport.
zbScroll line to the Bottom of the viewport.

Editing Text


Entering Insert Mode:

KeyInsertion Point
iInsert before current cursor position.
IInsert at the beginning of the line (first non-whitespace).
aAppend after current cursor position.
AAppend at the end of the line.
oOpen a new blank line Below and enter insert mode.
OOpen a new blank line Above and enter insert mode.
sSubstitute (delete current char and enter insert mode).
S / ccSubstitute entire line (clears line and enters insert mode).

Exiting Modes:

Press Esc or Ctrl + [ to return to Normal mode from any other mode.


Deleting (Cutting) Text:

KeyDeletion Scope
xDelete single character under cursor.
dwDelete from cursor to the start of next word.
d$ / DDelete from cursor to the end of the line.
ddDelete (cut) entire current line.
[n]ddDelete [n] consecutive lines (e.g. 5dd).

Undo and Redo:

KeyAction
uUndo last change.
Ctrl + rRedo the previously undone change.

Saving and Quitting

CommandOperation
:wWrite (save) buffer changes to disk.
:qQuit Vim (fails if unsaved changes exist).
:wq or :x or ZZWrite changes and Quit immediately.
:q! or ZQForce quit, discarding all unsaved changes.
:w [filename]Save current buffer to a new file name.

Advanced Techniques


Searching:

KeySearch Action
/patternSearch forward for pattern.
?patternSearch backward for pattern.
nJump to next matching occurrence.
NJump to previous matching occurrence.
*Search forward for exact whole word currently under cursor.
#Search backward for exact whole word currently under cursor.
:nohlClear search highlight matches from screen.

Search & Replace with Regex:

Vim uses the powerful :s (substitute) command for search and replace operations:

Command PatternDescription
:s/old/new/gReplace all occurrences of old with new in the current line.
:%s/old/new/gReplace all occurrences across the entire file.
:%s/old/new/gcReplace across file with confirmation prompt (y/n/a/q).
:%s/\<word\>/new/gMatch exact whole word only (word boundaries \< \>).
:%s/old/new/giCase-insensitive replacement.
:10,25s/old/new/gReplace only between lines 10 and 25 inclusive.

Text Objects: The Grammar of Vim

Text objects allow you to operate on structured code blocks (words, quoted strings, parentheses, HTML tags) regardless of where your cursor is positioned inside them. The syntax formula is: Operator + [i/a] + Object (where i = inner, a = around).

KeystrokeAction Description
ciwChange Inner Word (replaces current word without deleting surrounding spaces).
cawChange A Word (replaces word including surrounding whitespace).
ci" / ci'Change text Inside Quotes (e.g. transforms "hello" to "" in insert mode).
da" / da'Delete text Around Quotes (deletes quotes and their contents).
ci( or cibChange Inside Parentheses (...).
da( or dabDelete Around Parentheses (deletes parens and content).
ci{ or ciBChange Inside Curly Braces {...}.
citChange Inside HTML/XML Tag (e.g. <div>text</div>).
datDelete Around Tag (removes both tags and internal content).
vipVisually select entire Inner Paragraph.

Macros & The Dot Command (Automation)

  • The Dot Command (.): Instantly repeats your last editing change at the new cursor location. One of the single most productive keystrokes in Vim.
  • Vim Macros: Records an arbitrary sequence of normal/insert commands to a register to replay repetitively across multiple lines.
Macro CommandWorkflow Step
qaStart recording keystrokes into register a.
...Perform normal editing actions (e.g. I# <Esc>j).
qPress q in Normal mode to Stop recording.
@aReplay macro a once.
@@Repeat the most recently executed macro.
10@aExecute macro a 10 times consecutively.
:'<,'>normal @aRun macro a across all lines selected in Visual mode!

Copying (Yanking), Cutting, and Pasting:

KeyPurpose
yy / YYank (copy) the current line.
ywYank from cursor to start of next word.
ddCut the current line into the default register.
pPaste the copied or cut text After the cursor.
PPaste the copied or cut text Before the cursor.

Registers:

KeyPurpose
"[a-z]yyYank text into named register [a-z].
"[a-z]pPaste text from named register [a-z].
"+yCopy text to system clipboard (requires +clipboard Vim build).

:regDisplay contents of all active registers.

Splitting Screens (Windows):

Key / CommandWindow Action

:vsplit [file] or Ctrl+w vVertical window split.
Ctrl+w h,j,k,lMove cursor focus to Left, Down, Up, or Right window.
Ctrl+w =Equalize height and width of all split windows.
Ctrl+w q or :qClose current active window split.

Buffers & Tabs:

CommandNavigation Action

:b [num] or :b [name]Switch directly to buffer by ID or name.
:bnext (or :bn)Cycle to next buffer.

:bdelete (or :bd)Unload buffer from memory without closing Vim.
:tabnew [file]Open file in a brand new tab page.

Visual Mode

Visual mode allows you to highlight text regions and apply operators in batch:

KeyMode
vCharacter-wise Visual mode.
VLine-wise Visual mode.
Ctrl + vBlock-wise Visual mode (vertical column selection).
gvReselect the last visual block.
oToggle cursor to opposite end of visual selection.
~Toggle case of highlighted text.
> / <Indent / unindent highlighted block.

Production .vimrc Configuration

Place this configuration in your ~/.vimrc for modern keybindings, indentation, search highlighting, and custom multi-language comment toggling:

~/.vimrc 
" SETTING UP ENVIRONMENT ------------------------------------------------------------ {{{
set nocompatible
set number relativenumber " Hybrid line numbers for easy jumping
set ts=4 sw=4 smartindent expandtab " 4 space indentation
set incsearch hlsearch " Live search highlighting
set ignorecase smartcase " Case-insensitive search unless uppercase typed
syntax on
color elflord
set wildmenu
set wildmode=list:longest
set laststatus=2
" }}}

" KEY BINDINGS ------------------------------------------------------------ {{{
" Move lines up and down with Shift+Up / Shift+Down
nnoremap <S-Up> :m .-2<CR>==
inoremap <S-Up> <Esc>:m .-2<CR>==<Esc>i
vnoremap <S-Up> :m '<-2<CR>gv=gv
nnoremap <S-Down> :m .+1<CR>==
inoremap <S-Down> <Esc>:m .+1<CR>==<Esc>i
vnoremap <S-Down> :m '>+1<CR>gv=gv

" Save with Ctrl+s
nnoremap <C-s> :w<CR>
inoremap <C-s> <Esc>:w<CR>

" Clear search highlight with Escape in normal mode
nnoremap <Esc> :nohlsearch<CR>

" Toggle line comments with Ctrl+/
nnoremap <C-_> :call CommentToggle()<CR>
inoremap <C-_> <Esc>:call CommentToggle()<CR>i
vnoremap <C-_> :call CommentToggle()<CR>gv

function! CommentToggle()
    let l:filetype = &filetype
    let l:line = getline('.')
    let l:trimmed = substitute(l:line, '^\s*\(.\{-}\)\s*$', '\1', '')

    if (l:filetype ==# 'c' || l:filetype ==# 'cpp' || l:filetype ==# 'java' || l:filetype ==# 'javascript' || l:filetype ==# 'css')
        if l:trimmed[:1] !=# '//'
            execute "normal! I// \<Esc>"
        else
            execute "normal! ^xxx"
        endif
    elseif (l:filetype ==# 'python' || l:filetype ==# 'sh')
        if (l:trimmed[:1] !=# '# ')
            execute "normal! I# \<Esc>"
        else
            execute "normal! ^xx\<Esc>"
        endif
    elseif (l:filetype ==# 'html' || l:filetype ==# 'xml')
        if l:trimmed[:3] !=# '<!--'
            execute "normal! I<!-- \<Esc>A -->\<Esc>"
        else
            execute "normal! ^xxxxx$xxxx"
        endif
    elseif (l:filetype ==# 'vim')
        if (l:trimmed[:0] !=# '"')
            execute "normal! I\"\<Esc>"
        else
            execute "normal! ^x\<Esc>"
        endif
    endif
endfunction
" }}}
